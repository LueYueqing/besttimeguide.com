# AI文章图片缺失问题修复指南

## 问题描述

在使用 `//api/articles/ai-rewrite` API 生成文章时，发现很多已发布的文章没有图片。这与预期的两步流程不符：

### 预期流程

1. **阶段1**: DeepSeek 生成文章内容，包含图片占位符
2. **阶段2**: 根据占位符从 Pixabay 搜索图片，然后正式发布

### 实际问题

很多文章（如 id=214, 204等）虽然有内容，但没有图片就被发布了。

## 根本原因

### 1. AI 提示词不够清晰

原始的提示词虽然提到了图片占位符，但可能不够突出和具体，导致 DeepSeek 经常忽略这个要求。主要问题包括：

- 指令被淹没在其他内容要求中
- 没有提供足够的示例
- 没有强调这是"硬性要求"
- 格式说明不够详细

### 2. 代码逻辑漏洞

在 `app/api/articles/ai-rewrite/route.ts` 的 `processArticles()` 函数中，存在一个逻辑漏洞：

```javascript
} else {
  await prisma.article.update({
    where: { id: article.id },
    data: { aiRewriteStatus: 'completed' }
  })
  
  return { id: article.id, slug: article.slug, title: article.title }
}
```

这段代码在以下情况下执行：
- 文章有内容（`hasContent = true`）
- 但没有图片占位符（`hasPlaceholders = false`）

**问题**：当 DeepSeek 生成的内容中没有按照指令生成图片占位符时，这段代码会直接将文章标记为 `completed`，导致文章在没有图片的情况下就被跳过处理并发布。

## 解决方案

### 1. 改进 AI 提示词（关键修复）

重新设计了 `AI_GENERATE_PROMPT`，重点改进图片占位符的指令：

**主要改进点：**

#### a. 将图片占位符要求提升到最顶部
```markdown
## CRITICAL REQUIREMENTS - MUST READ

### Image Placeholders (MANDATORY - DO NOT SKIP)
You MUST include image placeholders in your article. This is a hard requirement.
```

#### b. 提供详细的格式说明和示例
```markdown
**EXACT FORMAT to use:**
```
![Descriptive alt text](IMAGE_PLACEHOLDER_1(search keywords for the image))
```

**Examples of correct image placeholders:**
- ![Beautiful cherry blossoms in spring](IMAGE_PLACEHOLDER_1(cherry blossoms spring japan))
- ![Traditional Japanese tea ceremony](IMAGE_PLACEHOLDER_2(japanese tea ceremony cultural))
- ![Modern Tokyo cityscape at night](IMAGE_PLACEHOLDER_3(tokyo cityscape night neon))
```

#### c. 明确7条关键规则
1. 使用精确格式：`![alt text](IMAGE_PLACEHOLDER_N(keywords))`，N从1开始递增
2. **必须**包含3-5个图片占位符
3. 第一个占位符放在介绍之后
4. 其余占位符放在主要章节的开头
5. 关键词应该是2-4个描述视觉内容的单词
6. Alt文本应该具有描述性和可访问性
7. **不要**使用实际图片URL - 只使用IMAGE_PLACEHOLDER格式

#### d. 提供完整的文章结构示例
```markdown
**Example of article structure with image placeholders:**

```
# Best Time to Visit Tokyo

Tokyo is a vibrant city... [introduction text]

![Scenic view of Tokyo skyline](IMAGE_PLACEHOLDER_1(tokyo skyline view))

## Best Seasons to Visit

Spring (March-May) is spectacular...

![Cherry blossoms in full bloom](IMAGE_PLACEHOLDER_2(cherry blossoms tokyo park))

Summer offers... [content]

## Top Attractions

Here are the must-visit places...

![Senso-ji temple in Asakusa](IMAGE_PLACEHOLDER_3(senso-ji temple asakusa historic))
```
```

#### e. 强调文章结构要求
```markdown
## Article Structure
1. Introduction (with an image placeholder at the end)
2. Section 1: Core information (with an image placeholder at the start)
3. Section 2: Deep dive or practical tips (with an image placeholder at the start)
4. Section 3: Additional context or related advice
5. FAQ (3-5 common questions)
6. Conclusion
```

#### f. 添加最终提醒
```markdown
**FINAL REMINDER:** Your article MUST include 3-5 image placeholders in the format `![alt text](IMAGE_PLACEHOLDER_N(keywords))`. Articles without image placeholders will be rejected.

Respond only with the Markdown content of the article. Ensure it includes the image placeholders.
```

**改进效果：**
- 使用大写和粗体强调重要性
- 提供多个具体示例
- 给出完整的文章结构示例
- 在多个位置重复提醒
- 明确说明没有占位符的文章会被拒绝

### 2. 修复 API 端点逻辑

修改 `app/api/articles/ai-rewrite/route.ts` 中的 `else` 分支：

```javascript
} else {
  // 有内容但没有图片占位符 - 这意味着AI没有按预期生成占位符
  console.warn(`[AI 流水线] 文章 ${article.title} 有内容但无图片占位符，需要重新生成`)
  
  // 清空内容并重置为pending，让AI重新生成（带有图片占位符）
  await prisma.article.update({
    where: { id: article.id },
    data: {
      content: '',
      aiRewriteStatus: 'pending',
      aiRewriteAt: new Date()
    }
  })
  
  console.log(`[AI 流水线] 已重置文章 ${article.title} 以重新生成（包含图片占位符）`)
  return { id: article.id, slug: article.slug, title: article.title }
}
```

**改进点**：
- 当检测到有内容但无图片占位符时，不再直接标记为 `completed`
- 而是清空内容并重置状态为 `pending`
- AI 将在下一次处理时重新生成内容，确保包含图片占位符

### 3. 修复现有已发布但没有图片的文章

创建了专门的脚本 `scripts/fix-articles-without-images.js` 来处理现有问题：

```bash
node scripts/fix-articles-without-images.js
```

**脚本功能**：
1. 扫描所有已发布且状态为 `completed` 的文章
2. 检查每篇文章是否包含：
   - 图片 markdown：`![alt](url)`
   - 图片占位符：`IMAGE_PLACEHOLDER_n(keywords)`
   - 封面图：`coverImage` 字段
3. 对于没有任何图片的文章，显示详细信息
4. 询问用户确认后，批量重置这些文章：
   - 设置状态为 `pending`
   - 清空内容
   - 清空封面图
   - 设置为草稿状态
   - 绕过冷却期

## 使用说明

### 修复现有文章

1. 确保数据库连接正常
2. 运行修复脚本：

```bash
node scripts/fix-articles-without-images.js
```

3. 脚本会列出所有没有图片的文章
4. 输入 `yes` 确认重置
5. 重置后的文章将在下次 AI 处理时重新生成

### 验证修复

1. 重置后，调用 AI 重写 API：

```bash
curl -X POST https://your-domain.com/api/articles/ai-rewrite
```

2. 检查文章是否重新生成了图片占位符
3. 确认图片搜索和上传是否正常
4. 验证文章是否正确发布
