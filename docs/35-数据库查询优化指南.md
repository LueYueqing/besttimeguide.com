# 数据库查询优化指南

## 问题概述

经过代码审查，发现项目存在以下数据库查询性能问题：

## 🔴 严重问题

### 1. 首页并发查询过多

**位置**: `app/page.tsx`

**问题**:
```typescript
const [travelPosts, socialMediaPosts, healthPosts, seasonPosts, monthPosts, weekPosts] = await Promise.all([
  getPostsByCategory('travel').then((posts) => posts.slice(0, 4)),
  getPostsByCategory('social-media').then((posts) => posts.slice(0, 4)),
  getPostsByCategory('health').then((posts) => posts.slice(0, 4)),
  getBestPostsForCurrentSeason(4),
  getBestPostsForCurrentMonth(4),
  getBestPostsForCurrentWeek(4),
])
```

每次首页加载执行：
- 3次分类查询（先查分类，再查文章）
- 3次时间标签查询
- 总计 9+ 次数据库查询

**影响**: 首页是最频繁访问的页面，性能直接影响用户体验和服务器成本

**解决方案**:
1. **使用缓存**: 添加unstable_cache，设置1小时缓存时间
2. **合并查询**: 考虑一次性查询多个分类的文章
3. **静态生成**: 使用 Next.js 的 generateStaticParams 预生成首页

**优化代码**:
```typescript
// lib/home.ts - 创建专门的首页查询函数
import { unstable_cache } from 'next/cache'
import { prisma } from './prisma'

export const getHomePageData = unstable_cache(
  async () => {
    // 一次性查询需要的所有文章
    const articles = await prisma.article.findMany({
      where: {
        published: true,
        publishedAt: { lte: new Date() },
        category: {
          slug: {
            in: ['travel', 'social-media', 'health'],
          },
        },
      },
      include: {
        category: true,
      },
      orderBy: {
        publishedAt: 'desc',
      },
      take: 12, // 每个分类最多4篇
    })

    // 在应用层按分类分组
    const travelPosts = articles.filter(p => p.category.slug === 'travel').slice(0, 4)
    const socialMediaPosts = articles.filter(p => p.category.slug === 'social-media').slice(0, 4)
    const healthPosts = articles.filter(p => p.category.slug === 'health').slice(0, 4)

    // 时间标签查询（保持现有逻辑，但添加缓存）
    const [seasonPosts, monthPosts, weekPosts] = await Promise.all([
      getBestPostsForCurrentSeason(4),
      getBestPostsForCurrentMonth(4),
      getBestPostsForCurrentWeek(4),
    ])

    return {
      travelPosts,
      socialMediaPosts,
      healthPosts,
      seasonPosts,
      monthPosts,
      weekPosts,
    }
  },
  ['home-page-data'],
  {
    tags: ['home-page'],
    revalidate: 3600, // 1小时
  }
)
```

### 2. 文章详情页查询所有文章

**位置**: `app/blog/[slug]/page.tsx`

**问题**:
```typescript
const allPosts = await getAllPosts() // 查询100条文章
const relatedPosts = allPosts
  .filter((p) => p.slug !== slug && (p.category === post.category || p.tags.some((tag) => post.tags.includes(tag))))
  .slice(0, 6) // 线上网站显示6篇相关文章
```

**影响**: 每次访问文章详情页都查询100条文章，但实际只需要6篇相关文章（根据线上网站显示的6篇）

**解决方案**: 创建专门的查询函数，只查询相关文章

**优化代码**:
```typescript
// lib/blog.ts - 添加新函数
export async function getRelatedPosts(
  currentSlug: string,
  currentCategory: string,
  currentTags: string[],
  limit: number = 6
): Promise<BlogPost[]> {
  try {
    // 优先查询同分类的文章（取前6篇）
    const categoryPosts = await prisma.article.findMany({
      where: {
        published: true,
        publishedAt: { lte: new Date() },
        slug: { not: currentSlug },
        category: {
          name: currentCategory,
        },
      },
      include: {
        category: true,
        author: true,
      },
      orderBy: {
        publishedAt: 'desc',
      },
      take: limit,
    })

    // 如果同分类文章足够，直接返回
    if (categoryPosts.length >= limit) {
      return mapToBlogPosts(categoryPosts)
    }

    // 否则查询有相同标签的文章（补足到6篇）
    const tagPosts = await prisma.article.findMany({
      where: {
        published: true,
        publishedAt: { lte: new Date() },
        slug: { not: currentSlug },
        id: { notIn: categoryPosts.map(p => p.id) },
        tags: {
          contains: currentTags[0], // 使用第一个标签
        },
      },
      include: {
        category: true,
        author: true,
      },
      orderBy: {
        publishedAt: 'desc',
      },
      take: limit - categoryPosts.length,
    })

    const allPosts = [...categoryPosts, ...tagPosts]
    return mapToBlogPosts(allPosts)
  } catch (error) {
    console.error('Error fetching related posts:', error)
    return []
  }
}
```

### 3. 标签查询效率低下

**位置**: `lib/blog.ts`

**问题**:
```typescript
export async function getAllTags(): Promise<string[]> {
  const articles = await prisma.article.findMany({
    where: {
      published: true,
      publishedAt: { lte: new Date() },
      tags: { not: null },
    },
    select: { tags: true },
  })
  
  const allTags = new Set<string>()
  articles.forEach((article) => {
    parseTags(article.tags).forEach((tag) => allTags.add(tag))
  })
  
  return Array.from(allTags).sort()
}
```

**问题**:
- 查询所有已发布文章的tags字段
- 在应用层解析JSON字符串
- 无法使用索引

**解决方案**:

**方案1: 使用数据库函数（推荐）**
```sql
-- 在数据库层面解析JSON数组
CREATE OR REPLACE FUNCTION get_all_tags()
RETURNS TABLE(tag text) AS $$
  SELECT DISTINCT jsonb_array_elements_text(tags::jsonb)
  FROM articles
  WHERE published = true
    AND published_at <= NOW()
    AND tags IS NOT NULL
  ORDER BY tag;
$$ LANGUAGE SQL STABLE;
```

```typescript
// lib/blog.ts
export async function getAllTags(): Promise<string[]> {
  try {
    const getCachedTags = unstable_cache(
      async () => {
        // 使用原生SQL查询
        const result = await prisma.$queryRaw<Array<{ tag: string }>>`
          SELECT DISTINCT jsonb_array_elements_text(tags::jsonb) as tag
          FROM articles
          WHERE published = true
            AND published_at <= NOW()
            AND tags IS NOT NULL
          ORDER BY tag
        `
        return result.map(row => row.tag)
      },
      ['all-tags'],
      {
        tags: ['all-tags'],
        revalidate: 3600, // 1小时
      }
    )
    
    return await getCachedTags()
  } catch (error) {
    console.error('Error fetching tags:', error)
    return []
  }
}
```

**方案2: 添加缓存**（快速修复）

### 4. 时间标签查询包含应用层过滤

**位置**: `lib/time-based-posts.ts`

**问题**:
```typescript
const articles = await prisma.article.findMany({
  where: {
    tags: { contains: seasonTag },
  },
})
// 然后在应用层再次过滤
.filter((article) => parseTags(article.tags).includes(seasonTag))
```

**解决方案**: 在数据库层面使用JSON查询

```typescript
export async function getBestPostsForCurrentSeason(limit: number = 4): Promise<TimeBasedPost[]> {
  try {
    const season = getCurrentSeason()
    const seasonTag = `season-${season}`
    
    const getCachedSeasonPosts = unstable_cache(
      async () => {
        const articles = await prisma.article.findMany({
          where: {
            published: true,
            publishedAt: { lte: new Date() },
            // 使用Prisma的json数组查询
            tags: {
              path: [],
              array_contains: [seasonTag],
            },
          },
          include: {
            category: true,
          },
          orderBy: [
            { viewCount: 'desc' },
            { publishedAt: 'desc' },
          ],
          take: limit,
        })
        
        return articles.map((article) => ({
          id: article.id,
          slug: article.slug,
          title: article.title,
          description: article.description || '',
          category: article.category.name,
          coverImage: article.coverImage,
          viewCount: article.viewCount,
        }))
      },
      [`season-posts-${season}`],
      {
        tags: [`season-posts`, `season-posts-${season}`],
        revalidate: 3600,
      }
    )
    
    return await getCachedSeasonPosts()
  } catch (error) {
    console.error('Error fetching season posts:', error)
    return []
  }
}
```

### 5. 部分查询未使用缓存

**影响**: 增加不必要的数据库查询

**解决方案**: 为所有频繁访问的查询添加缓存

```typescript
// lib/blog.ts - 为所有函数添加缓存

export async function getPostsByCategory(categorySlug: string): Promise<BlogPost[]> {
  try {
    const getCachedCategoryPosts = unstable_cache(
      async () => {
        const category = await prisma.category.findUnique({
          where: { slug: categorySlug },
        })

        if (!category) return []

        const articles = await prisma.article.findMany({
          where: {
            categoryId: category.id,
            published: true,
            publishedAt: { lte: new Date() },
          },
          include: {
            category: true,
            author: true,
          },
          orderBy: {
            publishedAt: 'desc',
          },
        })

        return mapToBlogPosts(articles)
      },
      [`category-posts-${categorySlug}`],
      {
        tags: [`category-posts`, `category-posts-${categorySlug}`],
        revalidate: 3600, // 1小时
      }
    )
    
    return await getCachedCategoryPosts()
  } catch (error) {
    console.error(`Error fetching posts by category ${categorySlug}:`, error)
    return []
  }
}

export async function getAllCategories(): Promise<string[]> {
  try {
    const getCachedCategories = unstable_cache(
      async () => {
        const categories = await prisma.category.findMany({
          where: {
            articles: {
              some: {
                published: true,
                publishedAt: { lte: new Date() },
              },
            },
          },
          orderBy: {
            order: 'asc',
          },
        })

        return categories.map((cat) => cat.name)
      },
      ['all-categories'],
      {
        tags: ['all-categories'],
        revalidate: 3600,
      }
    )
    
    return await getCachedCategories()
  } catch (error) {
    console.error('Error fetching categories:', error)
    return []
  }
}
```

### 6. Dashboard统计查询未缓存

**位置**: `app/api/articles/stats/route.ts`

**解决方案**: 添加缓存

```typescript
export async function GET(request: NextRequest) {
  try {
    const adminId = await checkAdmin()
    if (!adminId) {
      return NextResponse.json({ success: false, error: 'Unauthorized' }, { status: 401 })
    }

    const getCachedStats = unstable_cache(
      async () => {
        const [
          totalArticles,
          publishedArticles,
          draftArticles,
          featuredArticles,
          totalCategories,
        ] = await Promise.all([
          prisma.article.count(),
          prisma.article.count({ where: { published: true } }),
          prisma.article.count({ where: { published: false } }),
          prisma.article.count({ where: { featured: true, published: true } }),
          prisma.category.count(),
        ])

        const recentArticles = await prisma.article.findMany({
          where: { published: true },
          take: 5,
          orderBy: { publishedAt: 'desc' },
          select: {
            id: true,
            title: true,
            slug: true,
            publishedAt: true,
            category: {
              select: {
                name: true,
              },
            },
          },
        })

        return {
          stats: {
            total: totalArticles,
            published: publishedArticles,
            draft: draftArticles,
            featured: featuredArticles,
            categories: totalCategories,
          },
          recentArticles,
        }
      },
      ['article-stats'],
      {
        tags: ['article-stats'],
        revalidate: 300, // 5分钟
      }
    )

    const data = await getCachedStats()

    return NextResponse.json({
      success: true,
      ...data,
    })
  } catch (error) {
    console.error('Error fetching article stats:', error)
    return NextResponse.json({ success: false, error: 'Internal server error' }, { status: 500 })
  }
}
```

### 7. 数据库索引优化

**位置**: `prisma/schema.prisma`

**当前问题**:
- `tags` 字段是Text类型，无法创建传统索引
- `contains` 查询无法使用索引

**解决方案**:

**方案1: 使用PostgreSQL的GIN索引（推荐）**
```prisma
// prisma/schema.prisma
model Article {
  // ...其他字段...
  tags String? @db.Text // JSON数组格式
  
  // ...索引...
  @@index([slug])
  @@index([categoryId])
  @@index([authorId])
  @@index([published])
  @@index([publishedAt])
  @@index([featured])
  @@map("articles")
}
```

```sql
-- 创建GIN索引支持JSON查询
CREATE INDEX idx_articles_tags_gin ON articles USING GIN (tags::jsonb);

-- 如果需要查询tags中是否包含特定元素
CREATE INDEX idx_articles_tags_element ON articles USING GIN (tags::jsonb jsonb_path_ops);
```

**方案2: 添加复合索引**
```sql
-- 为常用查询添加复合索引
CREATE INDEX idx_articles_published_publishedAt ON articles(published, published_at DESC);

CREATE INDEX idx_articles_category_published ON articles(category_id, published, published_at DESC);

CREATE INDEX idx_articles_featured_published ON articles(featured, published, published_at DESC);
```
